# What I can do in English

_Read this through with your facilitator and tick together. It is fine if some are not ticked — you
will keep growing._

## Sounds and letters

- I can hear the first sound in a word.
- I know some letters.
- I can find my own name.

## Reading

- I can read the words **I · am · from · like**.
- I can sound out short words.
- I can match a word to a picture.
- I can read a short sentence about someone.
- I can find what I need on a notice or a timetable.
- I can read a longer story and understand the main idea.

## Writing

- I can write my own name.
- I can copy a sentence.
- I can fill in a form with my name and my age.
- I can write true sentences about myself.
- I can write a short note to somebody.
- I can write a letter about something that happened.

## Speaking

- I can say my name in English.
- I can say who I live with.
- I can say what I like.
- I can talk about a picture.
- I can answer questions about my day.
- I can talk about what I want to do next.
